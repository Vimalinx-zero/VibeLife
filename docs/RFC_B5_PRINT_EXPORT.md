## 🎯 背景与动机

### 用户痛点

1. **手抄错题效率低** - 抄一道题需要5-10分钟
2. **错题本无系统** - 复习时找不到题目，没有分类
3. **试卷管理混乱** - 卷子堆积如山，查找困难
4. **打印格式不标准** - 普通A4纸太大，不适合活页本

### 市场机会

- **寒假学习季** - 高中生集中补漏，弯道超车需求旺盛
- **B5活页本流行** - 小红书等平台"学霸笔记"多用B5格式
- **AI教育热点** - 结合AI整理+打印，形成差异化竞争

### 产品定位

> **"AI极速整理错题 + B5活页本打印 = 学习效率天花板"**

### B5规格参数

```javascript
const B5_SPEC = {
  // 纸张尺寸
  width: 176,      // mm
  height: 250,     // mm

  // 边距
  marginLeft: 18,   // mm（避让活页孔）
  marginRight: 8,   // mm
  marginTop: 15,    // mm
  marginBottom: 12, // mm

  // 内容区域
  contentWidth: 150, // mm

  // 活页孔位（6孔标准）
  holePunch: {
    type: '6-hole',
    positions: [20, 63, 106, 149, 192, 235], // mm from top
    diameter: 7,                             // mm
  },

  // 字体大小
  fontSize: {
    title: 16,
    heading: 12,
    body: 10,
    small: 8,
  }
};
```

### 排版算法

```javascript
// 智能排版逻辑
function layoutAlgorithm(mistakes, options) {
  const pages = [];
  let currentPage = { items: [], height: 0 };
  const maxHeight = B5_SPEC.height - B5_SPEC.marginTop - B5_SPEC.marginBottom;

  for (const mistake of mistakes) {
    const estimatedHeight = estimateHeight(mistake, options);

    // 检查是否需要分页
    if (currentPage.height + estimatedHeight > maxHeight) {
      pages.push(currentPage);
      currentPage = { items: [], height: 0 };
    }

    currentPage.items.push(mistake);
    currentPage.height += estimatedHeight;
  }

  if (currentPage.items.length > 0) {
    pages.push(currentPage);
  }

  return pages;
}
```
